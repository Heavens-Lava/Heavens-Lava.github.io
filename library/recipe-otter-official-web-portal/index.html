Web Portal Application Recipe

Full-stack web portal with HTTP routes, navigation menus, feedback forms, input validation, and persistent JSON storage.

ID: otter-official/web-portal Version: 1.0.0 License: MIT Framework: Otter >=1.0.1

Architecture & Runtime Preview

Otter >=1.0.1

The recipe combines Otter's native HTTP routing and static file serving with `otter-official/file-helpers` for saving form submissions and `otter-official/text-utils` for string formatting.

  1. 1setup-routes: Establish HTTP endpoints for portal pages, submission forms, and JSON API (otter-official/text-utils)
  2. 2persist-submissions: Store validated feedback and form submissions in persistent JSON storage (otter-official/file-helpers)

templates/server.ot.tmpl · otter 
# ==============================================================================
# Generated by Otter Application Recipe: web-portal 1.0.0
# Target: Native HTTP Web Portal with Form Submissions and File Persistence
# ==============================================================================

use "${import:otter-official/file-helpers}"
use "${import:otter-official/text-utils}"

a Submission has
    name
    email
    message
    timestamp
.

to validateSubmission name email message
    if name is ""
        return false
    .
    if not email contains "@"
        return false
    .
    if not email contains "."
        return false
    .
    if message is ""
        return false
    .
    return true
.

to createSubmission name email message
    s is a Submission
    name of s is name
    email of s is email
    message of s is message
    timestamp of s is "2026-11-10T18:00:00Z"
    return s
.

to saveSubmissions list filePath
    convert list to json into rawJson
    writeSafe filePath rawJson
    return true
.

to loadSubmissions filePath
    raw is readOrFallback filePath "[]"
    loaded is a thing
    convert raw from json into loaded
    return loaded
.

to getNavigation
    nav are empty
    add "Home" to nav
    add "Submissions API" to nav
    add "Contact" to nav
    return nav
.

# Web server declaration (Executed when started via `otter serve`)
site is a web server
    port is ${config:portNumber}
    host is "127.0.0.1"
    static is "public"
.

when site receives GET at "/api/nav"
    nav is getNavigation
    respond with nav as json
.

when site receives GET at "/api/submissions"
    subs is loadSubmissions "submissions_store.json"
    respond with subs as json
.

when site receives POST at "/api/submit" into req
    bodyData is a thing
    convert body of req from json into bodyData
    subName is name of bodyData
    subEmail is email of bodyData
    subMsg is message of bodyData
    if validateSubmission subName subEmail subMsg
        newSub is createSubmission subName subEmail subMsg
        currentSubs is loadSubmissions "submissions_store.json"
        add newSub to currentSubs
        saveSubmissions currentSubs "submissions_store.json"
        respond with newSub as json and status 201
    otherwise
        err has
            error is "Validation failed: invalid name, email, or message"
        .
        respond with err as json and status 400
    .
.

to validateSubmission name email message
    if name is ""
        return false
    .
    if not email contains "@"
        return false
    .
    if not email contains "."
        return false
    .
    if message is ""
        return false
    .
    return true
.

to createSubmission name email message

    name of s is name

to getNavigation
    nav are empty
    add "Home" to nav
    add "Submissions API" to nav
    add "Contact" to nav
    return nav
.

say "=== Web Portal Demo ==="
nav is getNavigation
say "Portal Navigation:"
for each item in nav
    say "  - " plus item
.

say "Validating incoming contact submission..."
isValid is validateSubmission "Ada Lovelace" "ada@analytical.org" "Enjoying the portal design!"
if isValid
    sub is createSubmission "Ada Lovelace" "ada@analytical.org" "Enjoying the portal design!"
    say "Submission accepted from: " plus name of sub
.
