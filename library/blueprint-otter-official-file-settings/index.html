File-Backed JSON Application Settings Blueprint

Load persistent JSON configuration with default fallbacks and write updates safely.

ID: otter-official/file-settings Version: 1.0.0 License: MIT Framework: Otter >=1.0.1

Architecture & Runtime Preview

Otter >=1.0.1

Uses file-helpers.readJsonObject to parse existing configuration safely, and file-helpers.writeJsonObject to save modified properties.

  1. 1Default Settings (input)
  2. 2Load or Fallback (pack-call: file-helpers.readJsonObject)
  3. 3Save Settings (pack-call: file-helpers.writeJsonObject)

templates/settings.ot.tmpl · otter 
# Generated by Otter Blueprint: otter-official/file-settings 1.0.0
# Standard editable Otter 1.0.1 source code

use "${import:otter-official/file-helpers}"

configPath is "${settingsFileName}"

defaultConfig has
    theme is "dark"
    autosave is true
    fontSize is 14
.

# Step 1: Read or initialize settings
settings is readJsonObject configPath
if settings is gone
    say "No settings file found. Initializing defaults..."
    writeJsonObject configPath defaultConfig
    settings is defaultConfig
.

say "Active configuration:"
say "  Theme:" theme of settings
say "  Autosave:" autosave of settings
say "  Font Size:" fontSize of settings

# Integration tests for file-settings Blueprint
use "../../../../packs/otter-official/file-helpers/src/main.ot"

testSettingsFile is "test_suite_settings.json"

cfg has
    app is "Otter Studio"
    version is 1
.

# Test 1: Write JSON settings
writeOk is writeJsonObject testSettingsFile cfg
if writeOk is true
    say "test 1 passed: settings written"
.

# Test 2: Read JSON settings
readCfg is readJsonObject testSettingsFile
if app of readCfg is "Otter Studio"
    say "test 2 passed: settings read accurately"
.

delete file testSettingsFile
say "All file-settings tests passed."

Installation & Usage

otter blueprint explain otter-official/file-settings
otter blueprint apply otter-official/file-settings --project ./my-app

Reads your application's settings.json file. If the file does not exist yet, it creates one with default values.
