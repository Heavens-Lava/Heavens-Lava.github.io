Game Actor Combat and Save-State Workflow

Demonstrates 3-pack composition with explicit state-mutation ordering: creates an Actor, inventory, and equipment with otter-official/game-entity, bounds incoming damage with otter-official/math-utils, and serializes/reloads game state using otter-official/file-helpers.

ID: workflow/game-actor-save-state Version: 1.0.0 License: MIT Framework: Otter Composition Planner (Phase 11)

Architecture & Runtime Preview

Otter Composition Planner (Phase 11)

Deterministic 11-step multi-pack DAG composing 3 Schema v2 Packs with explicit port bindings and side-effect ordering.

  1. 1step1_actor: otter-official/game-entity::createActor()
  2. 2step2_bound_dmg: otter-official/math-utils::clamp()
  3. 3step3_damage: otter-official/game-entity::applyDamage()
  4. 4step4_inv: otter-official/game-entity::createInventory()
  5. 5step5_item: otter-official/game-entity::createStackableItem()
  6. 6step6_add_item: otter-official/game-entity::addItemToInventory()
  7. 7step7_equip: otter-official/game-entity::createEquipment()
  8. 8step8_serialize: otter-official/game-entity::serializeGameState() [after: step3_damage, step6_add_item]
  9. 9step9_save: otter-official/file-helpers::writeJsonObject() [after: step8_serialize]
  10. 10step10_reload: otter-official/file-helpers::readJsonObjectSafe() [after: step9_save]
  11. 11step11_restore: otter-official/game-entity::deserializeGameState() [after: step10_reload]
