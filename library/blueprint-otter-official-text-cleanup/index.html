Text Sanitization and Slug Generator Blueprint

Clean raw user input into URL-safe slugs and padded identifier codes.

templates/cleanup.ot.tmpl · otter 
# Generated by Otter Blueprint: otter-official/text-cleanup 1.0.0
# Standard editable Otter 1.0.1 source code

use "${import:otter-official/text-utils}"

rawTitle is "Otter Language 2026 Release"
itemId is "42"
targetLen is ${codeTargetLength}

# Step 1: Generate clean URL slug
cleanSlug is slugify rawTitle

# Step 2: Format numeric code
formattedCode is padLeft itemId targetLen "0"

say "Original Title:" rawTitle
say "URL Slug:" cleanSlug
say "Formatted Code: #" formattedCode
