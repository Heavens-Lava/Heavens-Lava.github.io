Contact Manager with Validation Recipe

Desktop contact management application with input validation and file-backed persistence.

ID: otter-official/contact-manager Version: 1.0.0 License: MIT Framework: Otter >=1.0.1

Architecture & Runtime Preview

Otter >=1.0.1

The recipe defines a custom `Contact` type and combines `otter-official/text-utils` with structural string scanning to validate email format `@` and `.`. Valid entries are appended to a persistent list.

  1. 1validate-input: Perform email address structure and non-empty name assertions (otter-official/text-utils)
  2. 2persist-contacts: Save validated contact cards into JSON storage (otter-official/file-helpers)

templates/contacts.ot.tmpl · otter 
# ==============================================================================
# Generated by Otter Application Recipe: contact-manager 1.0.0
# Target: Contact Manager Application with File Persistence & Validation
# ==============================================================================

use "${import:otter-official/file-helpers}"
use "${import:otter-official/text-utils}"

a Contact has
    id
    name
    email
    phone
.

to validateEmail emailAddress
    if emailAddress is ""
        return false
    .
    if not emailAddress contains "@"
        return false
    .
    if not emailAddress contains "."
        return false
    .
    split emailAddress by "@" into atParts
    atCount is length of atParts
    if atCount is not 2
        return false
    .
    domain is last of atParts
    split domain by "." into domainParts
    dotCount is length of domainParts
    if dotCount is at least 2
        return true
    .
    return false
.

to createContact cid name email phone
    if not validateEmail email
        say "Error: Invalid email format for contact: "
        say email
        return gone
    .
    c is a Contact
    id of c is cid
    name of c is name
    email of c is email
    phone of c is phone
    return c
.

to searchContacts contacts term
    matches are empty
    for each c in contacts
        cName is name of c
        if cName contains term
            add c to matches
        .
    .
    return matches
.

to editContactPhone contacts targetId newPhone
    updated are empty
    for each c in contacts
        cid is id of c
        if cid is targetId
            phone of c is newPhone
        .
        add c to updated
    .
    return updated
.

to deleteContact contacts targetId
    remaining are empty
    for each c in contacts
        cid is id of c
        if cid is not targetId
            add c to remaining
        .
    .
    return remaining
.

to displayContacts contacts titleText
    say "=== " plus titleText plus " ==="
    countVal is length of contacts
    if countVal is 0
        say "(No contacts found)"
        return false
    .
    for each c in contacts
        cid is id of c
        cName is name of c
        cEmail is email of c
        cPhone is phone of c
        namePadded is padRight cName 18 " "
        emailPadded is padRight cEmail 24 " "
        lineParts are
            "#"
            cid
            ": "
            namePadded
            " | "
            emailPadded
            " | "
            cPhone
        .
        join lineParts with "" into line
        say line
    .
    return true
.

# ------------------------------------------------------------------------------
# Storage operations
# ------------------------------------------------------------------------------
to saveContactsToFile contacts filePath
    convert contacts to json into rawJson
    writeSafe filePath rawJson
    return true
.

to loadContactsFromFile filePath
    raw is readOrFallback filePath "[]"
    loaded is a thing
    convert raw from json into loaded
    return loaded
.

# ------------------------------------------------------------------------------
# Main Application Execution
# ------------------------------------------------------------------------------
storeFile is "contacts_store.json"

# Load saved contacts or initialize default directory
directory is loadContactsFromFile storeFile
dirLen is length of directory

if dirLen is 0
    say "Initializing new contact directory: ${config:companyBookName}"
    c1 is createContact 1 "Ada Lovelace" "ada@analytical.org" "555-0101"
    if c1 is not gone
        add c1 to directory
    .
    c2 is createContact 2 "Charles Babbage" "charles@engines.org" "555-0102"
    if c2 is not gone
        add c2 to directory
    .
    c3 is createContact 3 "Alan Turing" "alan@bletchley.uk" "555-0103"
    if c3 is not gone
        add c3 to directory
    .
    saveContactsToFile directory storeFile
.

displayContacts directory "${config:companyBookName}"
say "Active contact count:"
say length of directory

# Search by substring
adaMatches is searchContacts directory "Ada"

    say "FAIL: search Ada expected 1 match"
.

# Edit phone

cCharles is first of charlesFound
if phone of cCharles is not "555-9999"
    say "FAIL: phone update failed"
.

# Delete contact
directory is deleteContact directory 3

    say "FAIL: expected 2 contacts after delete"
.

# ------------------------------------------------------------------------------
# Test 4: End-to-End Persistence and Session Restart
# ------------------------------------------------------------------------------
testStorePath is "test_contacts_session.json"

# Save session 1
saveContactsToFile directory testStorePath

.
