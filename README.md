# Otter Website

This repository contains the published static output of the Otter documentation
website.

The pages are authored and compiled from Otter source in the `otterPS`
repository under `otter-docs/pages/`. This repository intentionally contains
only the deployable website files used by GitHub Pages.

## Local preview

Open `index.html` in a static-file server, or publish the `main` branch through
GitHub Pages.
